Storage transparency

Cookies & Local Storage

Canonical Shelf currently uses first-party storage for authentication, security, local-first study features, offline operation, and feedback reply routing—not for advertising or behavioral tracking.

Effective September 22, 2026

Current storage categories

Authentication/session cookies: used when you choose account features so Canonical Shelf can maintain an authenticated and secure session. A short-lived cookie cache may be used to reduce unnecessary authentication lookups.

Learning-state browser storage: stores local progress, review state, recent activity, and related learner state needed for guest/offline study.

Journal and personal study storage: stores private study writing locally unless you deliberately enable a feature that transfers or synchronizes it.

Theologian transcript storage: keeps the active conversation in this browser until New chat/Clear chat or browser-data clearing removes it.

Feedback queue: temporarily stores feedback locally when the service is offline or unavailable so it can retry later.

Pseudonymous feedback identifier: stores a random high-entropy identifier in this browser so a reviewer response can return to the same browser without requiring an account. The server stores only a one-way hash of this identifier with the feedback record.

Appearance/preferences: may remember user-selected interface preferences.

Service Worker / Cache Storage: stores application and content assets needed for installable/offline operation.

No advertising or behavioral analytics storage

Canonical Shelf currently does not use advertising cookies, advertising pixels, cross-site tracking, or behavioral analytics cookies. It does not sell browser identifiers or use them to build advertising profiles.

Why there is no “Accept all cookies” banner

The current cookies and similar storage are used to provide requested functionality, authentication/security, local-first continuity, or offline operation. Canonical Shelf does not ask you to “accept all” when there is no optional advertising or analytics tracking to accept. The service still discloses the storage it uses here and in the Privacy Policy.

If Canonical Shelf later adds optional analytics, advertising, profiling, or another nonessential storage technology, that technology must be separately disclosed and, where applicable, disabled until the learner has made the required choice.

Your controls

You can use browser settings to clear cookies, local storage, IndexedDB, and cache storage. Product-level controls may also clear specific data: New chat clears the local Theologian transcript, account deletion removes account-linked learner state as described in the Privacy Policy, and “Forget this browser's feedback link” removes the local anonymous feedback routing identifier.

Clearing site data can remove offline content, local progress, Journal writing, the active Theologian transcript, pending feedback, and the browser token needed to retrieve anonymous reviewer replies. Export or synchronize information you want to preserve before clearing browser data.
