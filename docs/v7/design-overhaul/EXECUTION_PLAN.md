# Canonical Shelf v7 — Visual Overhaul Execution Plan

1. Preserve the existing product/runtime capability baseline; prototype work must not mutate production learner state or content contracts.
2. Use the human-selected Living Folio screenshot as the fixed global visual language for the next gate.
3. Hold palette, typography, materiality, outer chrome, and application→object→apparatus hierarchy constant.
4. Build a Composition Lab with three materially distinct, implementable choices for each unresolved major surface: Home, Learn, Lesson refinement, Bible, Practice, Topics, and Theologian.
5. Make every prototype interactive enough to evaluate its real behavior: navigation, lesson progression, practice feedback, Bible selection, Topic exploration, and Theologian question submission/evidence layout.
6. Support desktop and phone recomposition in the same artifact; tablet behavior follows the same layout contracts and must be documented before production implementation.
7. Let the human select compositions independently per surface and expose a persistent selection summary.
8. Record the selected composition set as the Design Intent Artifact.
9. Only after all consequential surface choices are selected do production implementation nodes become eligible.
10. Implement the selected hybrid in coherent slices: global shell/tokens → Home/Learn → Study Focus → Bible → Practice → Topics/Theologian → utilities → responsive/motion/craft.
11. Validate each slice functionally and visually with representative real content and learner state.
12. Reopen the three-choice gate for any surface whose implementation evidence requires a material design-direction change.
13. Merge only after the complete site-level experience is coherent, current capabilities are preserved, and applicable release checks pass.

## Human gate
The Living Folio global visual language is selected. Production implementation remains blocked on the unresolved per-surface composition choices. A surface may not proceed into production implementation until its selected composition is explicitly recorded.
