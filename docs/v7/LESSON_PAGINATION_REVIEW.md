# Lesson pagination review

Generated by `bun scripts/lesson-pagination-report.mjs` from the build-time divider (S3.D, S3.D2). Do not edit by hand; edit the lessons, then regenerate.

## How to use this

- Every step of every lesson has been divided into cards. Each card is a step the learner sees; the first card keeps the step's id and later cards get `-2`, `-3`.
- **Nothing has been reworded.** Sentences are never split, content never moves between steps, and order never changes; the divider's tests check this for every lesson.
- Review section 1 first. Most seams in section 3 are fine; skim them for anything that reads oddly.
- To fix a break: mark the card id and what you want (move the break, merge, or reword). Rewording is allowed only at these breaks, and only after you approve each edit (`curriculum.lesson.pagination.revision-pass-2026-10-05`).
